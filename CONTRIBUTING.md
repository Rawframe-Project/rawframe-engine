# Contributing

Thank you for your interest in Rawframe Engine. It is source-available under the [Rawframe Source-Available License](LICENSE), and it takes issues only: it accepts no outside code.

## Issues are welcome

Bug reports are the most useful contribution. Search the existing issues first, then open one with the bug template: what you did, what you expected, what happened, the version and platform, and the last records of the program's log. A minimal game or configuration that reproduces it makes a fix much more likely.

Questions and ideas go to the repository's **Discussions**. A feature request starts there: describe the problem you want solved rather than an implementation, and a maintainer turns it into an issue when it is agreed.

Report security vulnerabilities privately through GitHub's private vulnerability reporting, as [SECURITY.md](https://github.com/Rawframe-Project/.github/blob/main/SECURITY.md) describes, never in a public issue.

## No pull requests

The engine is developed by its maintainers with AI coding agents, and its license does not take in outside code. Pull requests from outside the organization are closed automatically, whatever they change. If you have found a fix, describe it in an issue; a maintainer may make the change.

The Maul libraries and Kest, which the engine uses, are MIT-licensed and accept pull requests for issues a maintainer has approved; see the [organization's contributing guide](https://github.com/Rawframe-Project/.github/blob/main/CONTRIBUTING.md).
