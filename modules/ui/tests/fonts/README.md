# Test fonts

- `Ahem.ttf`: Ahem 1.50, from the Web Platform Tests
  (`https://github.com/web-platform-tests/wpt/blob/master/fonts/Ahem.ttf`),
  as Maul UI's tests keep it, unmodified. Its name table: "The Ahem font
  belongs to the public domain. In jurisdictions that do not recognize
  public domain ownership of these files, the following Creative Commons
  Zero declaration applies"
  (`http://labs.creativecommons.org/licenses/zero-waive/1.0/us/legalcode`).
  1000 units per em, ascent 800 and descent 200, every glyph a box an em
  wide, so text measures to exact values. SHA-256
  `b719ecb31c5b21fc573c03f6421c74ac63c271a5a3ff841e34f9705fb94b8448`.
